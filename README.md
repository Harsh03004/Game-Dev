# Game Development Projects

A collection of my game development and graphics programming work, including Unity projects, C++/SFML projects, AR experiments, 3D projects, and other coursework developed during my college studies.

## Purpose

This repository serves as an organized archive of my game development work.

It preserves the source code, project assets, configurations, and other relevant files required to understand and, where applicable, continue working on the projects.

Generated files and development caches are excluded where appropriate to keep the repository clean and reproducible.

- **Solar System** — Unity project based around a solar-system/space environment.

## Repository Notes

- This repository is an archive of game development work completed during college.
- Individual projects may have been created using different Unity versions and dependencies.
- Large binary assets are managed using **Git LFS**.
- Unity-generated directories such as `Library`, `Temp`, `Logs`, and `UserSettings` are excluded where applicable.
- Visual Studio generated files and build artifacts are excluded where applicable.
- Project-specific `.gitignore` files are preserved.
- The original project structure has been retained wherever possible.
- `Minor_Project-1` is intentionally not included in this repository because it is maintained in a separate repository.
- Unity versions used across the projects: `2022.3.18f1`, `2022.3.55f1`, and `6000.0.32f1`.

## Archive

The repository is primarily intended as a long-term archive of my game development projects, coursework, experiments, and supporting assets.

Individual projects should be opened from their respective directories using the appropriate development environment and project version.
